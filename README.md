## 它解决什么

大促主图最容易做成这样：五个卖点都高亮，三种红黄绿抢着出现，价格和卖点挤成一团，顾客找不到入口。

**Shop 009** 做减法，也做组织：

1. **先定这一张的任务**：品牌感、核心卖点、价格优势、食欲、新鲜、品质还是礼赠。整张只有一个最强信息中心。
2. **商品是真的、有重量的主体**，周围保持干净，装饰不穿过轮廓。
3. **颜色先保护商品**，再决定环境；全图只留少量真正有冲击力的强调色。
4. **文字成组**：标题、核心利益、辅助卖点、价格与购买、产地规格成分，靠字号、留白和位置区分，不靠堆颜色。
5. **价格的分量看商品**：高频促销品可以把价格做成锚点，高端礼赠品让品牌先出场。

> 小技巧：想让价格压过卖点，就把价格放在你给的卖点文字的第一句。排在最前的那句最容易成为大标题。

## 主图五连

一张图只能有一个最强信息中心，五张就能讲五件事。说“做一套”，它会先写分镜，给每张分一个任务：核心卖点、价格优势、品质感、食欲、礼赠……再分好这一张用哪几句文案、哪几条事实。色彩世界和标题字形跟第 1 张一致，构图张张不同。

- 价格只出现在价格那一张，不会每张都挂一个价签。
- 想自己定顺序，直接说，比如“核心卖点、价格、品质、食欲、礼赠”。
- 没给价格就没有价格页；没有材料支撑的任务不会硬凑，宁可少出一张。

## 你需要准备

- **商品图或商品名**（必需）。
- **卖点**（推荐）：一段话就够，它会提炼、分组。
- **价格、原价、活动时间、规格、产地、成分**（可选）：没给价格，画面就没有价格组，也不会出现占位价。

## 怎么用

### 第一步：安装（只需一次）

```bash
git clone https://github.com/nevertoday/xxd-shop-009.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-009" ~/.claude/skills/xxd-shop-009
```

Codex 用户把同一个文件夹链接到 `~/.codex/skills/xxd-shop-009`。装好后重开一次 AI 助手的会话。

### 第二步：用大白话说出你要什么

```text
/xxd-shop-009 这是空气炸锅，做一张双十一主图，到手价 299，原价 459，11.1–11.11，卖点 6L 大容量、可视窗口、免翻面
/xxd-shop-009 茶叶礼盒做一张中秋详情页首屏，突出礼赠，武夷山正岩产区，250g×2 罐
/xxd-shop-009 空气炸锅做一套主图五连
```

不用记参数。没说清的事（比如尺寸、张数），它会一次问齐；第二次用时可以直接沿用上次的设置。

### 第三步：它会这样做

1. 看你的商品图和描述，只问还没定的事；尺寸会按用途推荐比例，并告诉你像素。
2. 做一套时，先给你看分镜和第 1 张，你确认后再出其余几张。
3. 每个尺寸都重新构图，不是从一张图裁出来的。
4. 交付前逐张检查：商品有没有被改、字有没有写错、有没有多出你没给的数字。不通过的会告诉你并重做。
5. PNG 存进 `~/Desktop/xxd/xxd-shop-009/` 下新建的任务文件夹，把路径告诉你。

## 常见问题

**价格会出现在每一张上吗？**

不会。做套图时价格只在价格那一张；单张时价格的分量也会按商品定，礼赠类不会叫卖。

**需要什么才能用？**

三样东西：① 一个支持 Skills 的 AI 助手，比如 Claude Code 或 Codex；② 一个能出图的模型，可以是助手自带的出图能力，也可以是在 Codex 里配置好的、通过 Responses 接口出图的模型供应商（默认用 GPT Image 2）；③ 电脑上装有 Python 3.11 以上和 Pillow（`pip install pillow`）。

**要花钱吗？能商用吗？**

Skill 本身免费下载，出图费用由你自己的模型账户承担。给自己的商品、店铺、品牌出图（包括作为员工给任职公司出图）可以直接商用，不用申请；转卖 Skill、做成付费服务、收费帮别人出图，需要先取得作者的书面授权。详见文末“许可证”。

**出来的图有多大？**

你可以指定比例或准确像素。实际像素以模型返回为准，不会偷偷放大冒充高清，文件名里写的就是真实像素。

**图里的字会写错吗？**

AI 出图偶尔会写错字，或在品牌名旁多出 ® 这类小符号。交付前会逐张放大检查，发现问题就重做那一张；本页的样张都过了这一步。

**会不会乱写价格、销量？**

不会。画面上像事实的内容（价格、规格、产地、销量、获奖、认证……）只来自你提供的信息或商品图上看得清的字；没给就不写，也不放“¥XX”这种占位。

**能一次处理很多商品吗？**

能。把商品图文件夹交给它，每张图当作一件商品，尺寸和文字设置只问一次；每件商品的信息和文案互不串用。

## 它的原则

- **风格不走样：** 这款背后是一份成熟的商业设计提示词（[设计原文](references/original-prompt/zh-CN.md) · [English](references/original-prompt/en.md)）。Skill 不改写它，也不另加配色和美术指导，只把你的商品、尺寸、文字和事实交给模型。
- **商品不改款：** 有商品图时，造型、颜色、包装文字和 Logo 以图为准。
- **只用你给的事实，** 每件商品各管各的，不借用别的商品、旧成品或样张里的内容。
- **交付真实的 PNG 位图，** 不用 SVG 或代码绘图冒充；每次调用都新建任务文件夹。
- 画面上的每一个数字（价格、折扣、时间、规格）都能在你给的信息里找到。
