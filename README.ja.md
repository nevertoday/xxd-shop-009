## 解決すること

セール画像は、5つのメリットを同時に強調し、強い色を3つ混ぜ、価格を売りの中に押し込みがちで、お客さんは入口を見つけられません。

**Shop 009** は引き算と整理をします。

1. **この1枚の役割をひとつに決める：** ブランド、一番のメリット、価格、食欲、鮮度、品質、贈り物。1枚に最強の中心はひとつ。
2. **重さのある本物の商品、** すっきりした周り、輪郭にかかる装飾なし。
3. **まず商品の色を守り、** それからシーンを決める。本当に効くアクセントだけを少数残す。
4. **文字をまとめる：** タイトル、一番のメリット、その他のメリット、価格と購入、産地と仕様。色を増やすのではなく、大きさ・余白・位置で分ける。
5. **価格の大きさは商品しだい：** 高頻度の販促ならアンカーに、上質なギフトなら控えめに。

> コツ：価格をメリットより目立たせたいなら、渡すセールスコピーで価格を最初に書いてください。最初の一文がいちばん見出しになりやすいからです。

## メイン画像5連セット

1枚に最強の中心はひとつなので、5枚なら5つのことを言えます。セットを頼むと絵コンテを書き、1枚ずつにひとつの役割（一番のメリット、価格、品質、食欲、贈り物…）と、あなたのコピーと事実のうちの担当分を割り当てます。色の世界と見出しの文字は1枚目に合わせ、レイアウトはすべて変えます。

- 価格は価格の画像だけに載せ、全部の画像にタグとして付けることはしません。
- 順番を自分で決めたいときは、「一番のメリット、価格、品質、食欲、贈り物」のように言うだけです。
- 価格がなければ価格の画像はなし。裏付ける素材のない役割は、水増しせずに外します。

## 用意するもの

- **商品画像または商品名**（必須）。
- **売り**（推奨）：文章ひとつで十分。抜き出してまとめます。
- **価格・通常価格・期間・仕様・産地・原材料**（任意）：価格がなければ価格のまとまりも仮の価格も出しません。

## よくある質問

**価格は全部の画像に載りますか？**

いいえ。セットでは価格は価格の画像だけ。1枚の画像では価格の重さは商品しだいで、ギフトを押し売りすることはありません。

**何が必要ですか？**

3つです。① Claude Code や Codex など、Skills に対応した AI アシスタント。② 画像を生成できるモデル。アシスタント内蔵の画像生成、または Codex に設定したモデルプロバイダーで Responses API 経由で画像を生成するもの（既定は GPT Image 2）。③ Pillow 入りの Python 3.11 以上（`pip install pillow`）。

**お金はかかりますか？商用利用できますか？**

Skill は無料でダウンロードできます。画像生成の費用はあなた自身のモデルアカウントに請求されます。本プロジェクトは PolyForm Noncommercial ライセンスです。個人の学習・研究・テストには使えますが、ショップ運営、受託制作などの商用利用には事前に作者の書面による許可が必要です。末尾の「ライセンス」を参照してください。

**画像の大きさは？**

比率か正確なピクセル数を指定できます。実際のサイズはモデルが返したとおりで、こっそり拡大することはなく、ファイル名に本当のピクセル数が書かれます。

**画像内の文字に誤字は出ますか？**

AI の画像では、ときどき文字を間違えたり、ブランド名の横に ® のような小さな記号を足したりします。納品前に1枚ずつ拡大して確認し、通らないものは作り直します。このページの作例はすべてその確認を通っています。

**価格や販売数をでっち上げませんか？**

しません。価格、仕様、産地、販売数、受賞、認証など事実に見えるものは、あなたが提供したものか、商品にはっきり読める文字からだけ取ります。それ以外は載せず、「¥XX」の仮置きもしません。

**たくさんの商品を一度に処理できますか？**

できます。商品画像のフォルダを渡してください。1枚の画像に商品1つ、サイズと文字は一度だけ質問され、ある商品の事実やコピーが別の商品に混ざることはありません。
